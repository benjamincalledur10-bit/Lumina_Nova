# Logo de Lumina Nova

Creado con la herramienta integrada `image_gen`. Una estrella angular de cuatro puntas,
ligeramente inclinada, con estela corta, una N en negativo, centro blanco, borde cian
eléctrico y fondo azul muy oscuro. Sin texto.

- [Original](lumina-nova-original.png), conservado para futuras exportaciones.
- Icono de Mod Menu: `src/main/resources/assets/luminanova/icon.png` (128 × 128).
- Logo de la pantalla General: `src/main/resources/assets/luminanova/logo-small.png` (28 × 28).

Las exportaciones se redujeron con `sips`; no cambian el diseño del original.

## Prompt utilizado

> Use case: logo-brand. Create a square Minecraft performance mod icon for Lumina Nova. A single clean angular four-point star tilted slightly clockwise, with a small tapered speed trail sweeping toward lower left. White luminous core, crisp electric cyan edges, soft restrained glow, very dark navy blue background filling the entire square. Subtly integrate an N using negative space inside the star while keeping the four-point silhouette unmistakable. Flat vector-like geometric mark with minimal details, legible at 32x32 pixels, centered with generous padding. No text, no letters outside the mark, no extra stars, no border, no mockup. Final production icon.
